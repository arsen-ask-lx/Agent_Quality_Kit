## Их проба — наш `probe`, сделанный заданием модели

`SKILL.md`, раздел `Probe`, дословно:

> The command inventory proves only that commands exit 0. The probe proves the repository can
> guide a change to a *verified* fix.
>
> introduce one small, reversible defect inside the Gate 3 scope: invert a boolean, shift a
> boundary, drop a required field, change a public return value […]
> Run the verification and confirm it catches the defect. **If nothing fails, that is a P0 or P1
> fix record**

И среди того, что искать (раздел 5): «commands whose failures or exit codes are masked», «CI jobs
that configure a tool without exercising meaningful behavior». Определение из словаря отчёта:
«Enforced control — Something that actually fails when violated».

Разница с нашим `probe`: их дефект **смысловой** (`a + b` → `a - b`), он проверяет тесты; наш —
красный образец каталога (печать, проглоченная ошибка) в горячий файл, он проверяет линтеры и
сторожей. Их вариант сильнее для тестов, наш — для статических проверок.

## Цена и устройство

- время: около 4 минут на близнеца на этой машине; токены не замерены
- вердикт — суждение модели по тексту: воспроизводимость между запусками не проверена, в
  конвейер на каждый pull request так не поставить
- правит рабочее дерево (проба) и ставит зависимости (`npm install`); откат — сверкой хешей,
  проверено: после прогона в дереве только `reports/`

## Что брать себе

1. **Проверка «объявленная команда вообще выполняется»** — `npm ci` без lock-файла, конфиг
   линтера, которого нет. Это `ci-actually-fails` с другой стороны: не «гасит ли шаг ошибку», а
   «дойдёт ли до шага». Кандидат в каталог; нужен случай из живого репозитория
2. **`|| true` в хуке** — то же, что вывел разбор `agents-shipgate.md`; теперь два независимых
   указания
3. **Смысловая мутация в пробе** для тестов — дополнение к нашему `probe`, а не замена. Новая
   возможность — решение владельца, заморозка `PROJECT.md` §9а
4. **«Самая дорогая блокировка»** — в отчёте названа одна находка, починка которой не помогает
   без другой (снять `|| true` бесполезно, пока тест ничего не утверждает). У нас «начните с этих
   трёх» порядок не объясняет

## Чего не брать

- вердикт модели как арбитр — наш свод требует машинную проверку
- балл 0–105 с весами по областям — у близнецов 34 и 27, разница в балле мала при полярной
  разнице в защите; решает у них не балл, а ворота и проба

## Не проверено

- повторяемость: каждый близнец прогнан один раз
- на живом большом репозитории — только близнецы
- другие модели и агенты (Codex, Gemini)
