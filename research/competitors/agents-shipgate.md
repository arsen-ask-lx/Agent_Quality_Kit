## Что это на самом деле

«Детерминированный гейт слияния для изменений, которые меняют, что **может** агент». Читает
статически `.claude/settings.json`, `.mcp.json`, настройки Codex/Cursor, выгрузки MCP и OpenAPI,
определения инструментов в фреймворках агентов — и сравнивает ветку с базой: какие разрешения
добавлены, какие запреты сняты, какие инструменты появились. Ничего не запускает.

**Соседи по предмету, а не по вопросу.** Их вопрос — «что агенту стало можно», наш — «может ли
проверка покраснеть». Пересекаемся в одном месте: изменение, которое снимает защиту.

## Опыт: чем снятие защиты отличается от любой правки

Репозиторий с хуком `Stop` → `npm test` и запретом `Bash(git commit --no-verify:*)`. Три ветки:

| изменение | shipgate 1.0.0 `diff` | AQK 0.16.0 |
|---|---|---|
| хук → `npm test \|\| true`, запрет удалён | `⚠ high widened Stop → Stop` · `⚠ low removed Bash(git commit --no-verify:*)` | **молчит**: `hook-actually-fires` код 0 |
| хук → `npm test -- --test-reporter=dot` (безвредно) | `⚠ high widened Stop → Stop` — **то же самое** | молчит |

Два вывода, оба неудобные:

1. **Их «high» не отличает выключение проверки от смены вывода.** Правка хука — всегда «widened».
   Для их вопроса честно: изменилось то, что крутится вокруг агента. Для нашего — шум.
2. **Мы не видим `|| true` в хуке Claude Code вовсе.** `hook-actually-fires` проверяет имя
   события, matcher и существование файла команды; гашение исхода в самой команде — нет. Тот же
   класс, что `pytest || true` в конвейере, который `ci-actually-fails` ловит. Близнецы с husky
   (`.husky/pre-commit` → `npm test || true`) тоже прошли мимо AQK. **Пробел в каталоге, не их
   заслуга** — найден этим разбором.

## Что у них сильнее нас

- **Снятие запрета — отдельная строка вывода.** `removes a denial the agent was subject to`. Наш
  `protection-not-removed` сторожит только гейты в `.aqk.yml`; удаление `deny` из настроек агента
  не видит никто из нашего каталога
- **Не смогли прочитать ≠ чисто**, дословно из README: «`Cannot compare against <base>: <reason>`
  when an input could not be read, which is an input limit and never a quiet pass». Тот же третий
  исход, что наш `?`, — пришли к нему независимо
- **Корпус из чужой истории** (`benchmark/miner`): прогон движка по влитым PR публичных
  репозиториев агентов, строка на PR. 241 PR, и честная запись в `CALIBRATION.md`: пороги
  «never tuned against data», разметка человеком «unstarted». Это наш инструмент 1 из
  `.claude/skills/growth`, сделанный как программа и с тем же долгом — разметки нет

## Что брать себе

1. **`|| true` в команде хука** — в `hook-actually-fires` четвёртым классом, рядом с
   существованием файла. Та же граница, что у `ci-actually-fails`: закрытый список запускалок
   (`npm test`, `pytest`, …), а не любая команда. Нужен случай из живого репозитория до записи
   (правило `proof-from-journal`) — поиск кода по `settings.json` и `.husky/`
2. **Снятый запрет в настройках агента** — кандидат в `protection-not-removed`: `deny` в
   `.claude/settings.json` на базе есть, в ветке нет. Сначала замер частоты: сколько живых
   репозиториев вообще держат `deny`
3. **Форма «Not compared: …»** — перечисление того, что не прочитано, до вывода, а не после. У нас
   такое есть в `report --since` (три состояния файла); сверить, что `doctor` говорит о
   непрочитанном так же прямо

## Чего не брать

- уровни риска `high/medium/low` на любую правку — у них это оправдано вопросом, у нас стало бы
  шумом
- разбор фреймворков агентов (LangChain, CrewAI, ADK) — другой предмет, расширение вширь
  заморожено (`PROJECT.md` §9а)
