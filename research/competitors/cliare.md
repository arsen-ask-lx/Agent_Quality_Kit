## Что это на самом деле

Не сосед. Меряет, **удобен ли сам CLI агенту**: какие команды есть, какие флаги, есть ли
машиночитаемый вывод, пишут ли «безопасные» команды на диск. Бинарник щупается снаружи, как
чёрный ящик, в песочнице. К вопросу «может ли проверка покраснеть» отношения не имеет.

Полезен как **чужой инструмент по нам** (инструмент 7 из `.claude/skills/growth`): AQK — CLI, и
его читают агенты.

## Прогон по `aqk` 0.16.0

`cliare measure aqk --profile standard` в пустом git-каталоге, с отдельным `HOME`:

| | |
|---|---|
| оценка | 40/100, `experimental_partial` |
| команд обнаружено | **0** (в справке 24 строки) |
| побочных записей на диск | 0 |
| отказ на неверную команду | чистый (recovery 100) |

«Команд 0» — не их ошибка. Разбор причины нашёл у нас **два настоящих дефекта**:

1. **`aqk --help`, `aqk -h` и `aqk help` возвращают код 1.** Справка печатается веткой
   «неизвестная команда» (`tool/program.mjs`, `process.exit(cmd ? 1 : 0)`), и `--help` — тоже
   «неизвестная». Агент и любой инструмент читают код 1 как «справки нет». Стандарт GNU,
   дословно: «The standard `--help` option should output brief documentation for how to invoke
   the program, on standard output, then exit successfully» (gnu.org/prep/standards, раздел
   `--help`, сверено 2026-09-16). `clig.dev` про код возврата справки не говорит ничего
2. **Цвет печатается и в трубу.** `c.bold` в `tool/lib/core.mjs` оборачивает строку в escape-коды
   всегда: `aqk --help | cat -v` даёт `^[[1maqk^[[0m`. `isTTY` и `NO_COLOR` не проверяются нигде,
   кроме индикатора прогресса. Агент читает вывод через трубу — то есть **всегда** с мусором.
   `clig.dev`, дословно: цвет выключают, когда «`stdout` or `stderr` is not an interactive
   terminal (a TTY)» и когда «The `NO_COLOR` environment variable is set and it is not empty»
   (сверено 2026-09-16)

Третье — не дефект, а граница: машиночитаемого вывода (`--json`) у `doctor`/`vitals` нет. Это
новая возможность, заморожено (`PROJECT.md` §9а); агенту сейчас служит `aqk context`.

## Что брать себе

- ничего из их модели: чужой предмет
