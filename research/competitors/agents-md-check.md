# `duke5am/agents-md-check` — линтер сводов, у которого главное правило работает наоборот

> **Что это.** Статический линтер файлов, которые читают агенты: `AGENTS.md`, `CLAUDE.md`,
> `.cursor/rules/*.mdc`. Python, без зависимостей, MIT, 1785 строк в `lint.py`.
> Создан 2026-09-18, последний пуш 2026-09-20, звёзд 0 (сверено `gh repo view` 2026-09-23).
>
> **Зачем нам.** Это ближайший сосед по намерению «свод агента врёт про репозиторий» — тот самый
> класс, где у нас живёт `entry-commands-exist` и откуда 2026-09-15 вылетела `entry-links-exist`.
> Разбор — по коду и прогоном, как требует `.claude/skills/growth`, раздел 2.

## Что он умеет: 20 правил

| код | что ловит |
|---|---|
| `AGL001` | правило ссылается на путь, которого нет |
| `AGL002` | два правила противоречат друг другу в одном разделе |
| `AGL003`/`AGL004` | правило повторено дословно / почти дословно |
| `AGL005`/`AGL006` | свод больше бюджета / меньше бюджета |
| `AGL007`–`AGL012` | заголовки `.mdc` у Cursor: нет, битые, без описания, чужой ключ, все `alwaysApply`, пересекающиеся маски |
| `AGL013`–`AGL018` | правило до первого заголовка, скачок уровня заголовка, пустой раздел, правило-вопрос, правило человеку, правило непроверяемое |
| `AGL019` | **`CLAUDE.md` и `AGENTS.md` разошлись** |
| `AGL020` | лежит только один из двух файлов |

Половина списка — про форму документа, и это честная работа: `AGL007`–`AGL012` читают структуру
`.mdc`, которую мы не читаем вовсе.

## Близнецы: правило `AGL019` срабатывает на починке и молчит на дефекте

Обязательная часть разбора — два проекта, одинаковых во всём, кроме способности проверки
провалиться. Здесь близнецы такие: в обоих два свода в корне, различается только раскладка.

Прогон 2026-09-23, версия из `HEAD`:

| близнец | что в нём | вердикт `agents-md-check` | наш вердикт |
|---|---|---|---|
| **зелёный** | `CLAUDE.md` — одна строка `@AGENTS.md` | **HIGH `AGL019`**, «token overlap 2 %» | молчит |
| **красный** | почти копия: `AGENTS.md` велит Go 1.25.13 и SDK v0.3.1, `CLAUDE.md` — Go 1.26 и v0.5.0 | **молчит** (сходство 87 %) | **красное**, обе строки названы |

Причина — в одной строке `lint.py`:

```python
sim = token_similarity(tokenize(claude.text), tokenize(agents.text))
if sim >= DIVERGENT_PAIR_SIMILARITY:   # 0.55
    continue
```

Правило краснеет, когда своды **НЕ похожи**. Но непохожесть — это чаще всего указатель
(`@AGENTS.md`) либо два намеренно разных документа; а разъехавшаяся копия по определению похожа
на оригинал. Совет, который он печатает на зелёном близнеце, — «make one file the source of truth
and reduce the other to a pointer» — предлагает сделать то, чем файл уже является.

**Тот же промах у живого человека, независимо от нас.** `modelcontextprotocol/inspector#2427`
(2026-09-18): сообщение «оба свода лежат в корне, проверки расхождения нет» по статическому
чтению. Сопровождающий закрыл в день подачи:

> `CLAUDE.md` at the repo root is a single line: `@./AGENTS.md` … there is nothing that can drift
> from `AGENTS.md` and nothing for a drift check to compare.

Два независимых случая одной ошибки — это уже не случайность, а форма класса: **судить раскладку
по размеру файлов, не открыв их.**

## Что мы отсюда взяли и чего не взяли

**Взяли — постановку вопроса.** Пара сводов как объект проверки: до этого разбора у нас была
только связка «свод → команда». Запись `entry-docs-agree` заведена 2026-09-23 после замера по
300 чужим репозиториям.

**Не взяли — направление сравнения.** У нас красное это след **копии, которая разъехалась**:
общая половина строк плюс расхождение. Замер на 85 чужих парах: 4 красных, все настоящие.
Их правило на той же выборке обвинило бы прежде всего 58 репозиториев с указателем.

**Не взяли — `AGL020` («лежит только один из двух файлов»).** Это требование заводить второй
документ, а не проверка того, что защита работает. Репозиторий с одним `AGENTS.md` ничего не
нарушает: Claude Code читает его через `@`-включение или символьную ссылку, и навязывать второй
файл — значит плодить ровно ту пару, которая потом разъедется.

**Не взяли — `AGL016`–`AGL018`** («правило-вопрос», «правило человеку», «правило непроверяемое»).
Это чтение свободного текста по словарю оборотов (`industry-standard` и подобные). Наш
собственный запрет прямой: запись опознаёт конструкцию, а не понимает текст (`SPEC.md` §6), и
две записи, нарушившие его, из каталога удалены.

**Присматриваемся — `AGL011`** («все файлы правил стоят `alwaysApply: true`»). Это про бюджет
внимания агента, и это конструкция, а не текст. Замера у нас нет, поэтому записи нет.
