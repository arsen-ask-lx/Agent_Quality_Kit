> **Зачем.** Половина кандидатов отсеивается при проверке у первоисточника, и каждый отказ — это
> знание. Без журнала разбор начинают заново, а ещё хуже — не начинают и пишут.

> **Правило:** строка появляется здесь ДО отправки, вместе с тем, чем проверено. Отказ
> записывается так же подробно, как отправка: он дороже.

## Отклонено при проверке — и почему

| кандидат | что показала проверка |
|---|---|
| `exoscale/cli` — «в своде `make build`, цели нет» | их Makefile начинается с `include go.mk/init.mk`; `go.mk` — подмодуль git, которого в клоне нет, цель объявлена там. **Стало правкой гейта:** при неподключённом файле молчим обо всех целях make и говорим, что не проверили |
| `botiverse/hands` — «пакета `@botiverse/hands-feedback-react` нет в реестре» | в их же документации строкой выше написано «After the npm package is published» — они знают и пишут об этом сами. Решение человека, гейту тут делать нечего |
| `EricDenis01/ericdenis` — «в своде `npm run check`, скрипта нет» | в их своде это ПРИМЕР с оговоркой: «such as `npm run check` / `pnpm check` **when the repo provides it**». Читать намерение машина не умеет — решение человека |
| `Gerstep/HumanCompiler` — «скрипта `scripts` нет» | у них `bun run scripts/generate-plugin.ts` — запуск ФАЙЛА, а не скрипта. **Стало правкой гейта** |
| `andyhartzler/my-bluebubbles-web` — «целей `a`, `and`, `it`, `one` нет» | «make it go away» в прозе; Makefile в репозитории нет вовсе. **Стало правкой гейта** |
| `Aurealibe/claude-config`, `Weaverse/.agents` — «npm-команд нет» | это сборники правил для ДРУГОГО проекта, своего package.json у них нет и не должно быть. **Стало правкой гейта** |
| `aashaexo/soundshuman` — «конвейер ставит выдуманный пакет» | весь блок шага **закомментирован** решёткой, он выключен целиком. **Стало правкой гейта:** закомментированная строка больше не читается как команда |

## Мера

Несколько писем в день, не десятки. Поток одинаковых сообщений с одного аккаунта читается как
рассылка, и это необратимо. Машина эту меру не сторожит — только внимание того, кто пишет.
