# Шаблоны гейтов

Пока пусто — и это намеренно.

Гейт стережёт существующий артефакт. Шаблоны появляются здесь из реальной работы: поставили
гейт в проекте, он поймал настоящий брак — обобщили и положили сюда вместе с **красным и
зелёным образцами**. Заранее наполнять этот каталог значит собирать коллекцию мёртвых правил.

Первый кандидат — храповик долга: реестр известных нарушений + проверка «список может только
укорачиваться». Механика описана в `../README.md` и в скилле `bootstrap-harness`.
