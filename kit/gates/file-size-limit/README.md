# Файл не вырастает до размера, в котором агент теряется

**Намерение.** Прод-код не длиннее 500 строк, компонент интерфейса — 300, тест — 800.

**Какой отказ это поймало.** В разборе 1069 коммитов за 90 дней работы с агентами нашёлся
**один файл маршрутов на 6305 строк**. Дословно: «не потому что так задумано, а потому что каждую
новую фичу дописывали туда же — агенту так ближе по контексту».
Запись в журнале: `incidents/README.md`, 2026-08-25.

**Почему машина, а не внимательность.** Файл растёт по одной строке за раз, и ни одна правка не
выглядит как «пора делить». Момент, когда стало поздно, не наступает — он проходит незаметно.

**Числа спорные, предел — нет.** Можно спорить, 500 или 700; нельзя работать без предела вообще.
Свои числа правятся в `check.sh` одной строкой.

**Чего НЕ ловит.** Длину функции и вложенность: файл на 200 строк с одной функцией в 180 строк
проверку пройдёт. Это отдельная мера — цикломатическая сложность.

**Готового аналога нет.** Проверено: среди 964 правил `ruff` предела на
размер файла нет ни одного. Это тот случай, когда свой гейт законен.

**Образцы.** `red/` — прод-файл на 600 строк. `green/` — тот же код, разделённый надвое.
