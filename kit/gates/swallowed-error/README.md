# Ошибка не глушится молча

**Намерение.** Ошибка либо обработана и записана в лог, либо проброшена дальше. Третьего нет.

**Какой отказ это поймало.** В разборе 1069 коммитов за 90 дней: **1436 блоков перехвата, из
которых лишь около 10% пробрасывают ошибку дальше.** Остальные глушат её в лог или возвращают
пустоту. Цена — три недели поиска источника отказов, которые гасились на месте.
Запись в журнале: `incidents/README.md`, 2026-08-25.

**Почему машина, а не внимательность.** Пустой перехват выглядит безобидно и пишется быстрее
правильного. В ревью на 400 строк он не читается как дефект — он читается как аккуратность.

**Что именно ищется.** Перехват с пустым телом: `except …: pass` и `…: ...` в Python, пустой
`catch (…) { }`, пустой `.catch(() => {})`.

**Чего НЕ ловит.** Перехват, который что-то делает, но не то: записал в лог на уровне `debug` и
вернул пустоту — формально не пустой, по сути тот же тихий отказ. Это остаётся человеку.

**Готовый аналог есть, и он подробнее.** В Python три правила `ruff`
покрывают разные оттенки: `BLE` — ловля голого исключения, `TRY400` — запись в лог без трейса,
`SIM105` — перехват ради тишины. В TypeScript — `no-empty` с запретом пустого перехвата.
Измерено на живом проекте: `TRY400` нашёл 47 мест, которые самописный разбор искал час.
Рецепты под эти стеки берут готовое; своя проверка — запасная.

**Образцы.** `red/` — Python и JavaScript с пустым перехватом. `green/` — тот же код: запись в
лог и проброс.
