# CLAUDE.md

Свод для агента: как здесь собирают, проверяют и оформляют изменения.

## Сборка и проверки

- **Go 1.26** — нижняя граница тулчейна из `go.mod`.
- Внешний SDK закреплён: `znn-sdk-go` версии v0.5.0.
- `go build ./...` собирает всё дерево.
- `go test ./...` обязан пройти до коммита.
- Форматирование: `gofmt -l .` должен молчать.

## Соглашения

Сервисы живут в `app/`, каждый отдельным швом: `WalletService`, `NodeService`, `TxService`.
Ошибку не глотаем: либо возвращаем выше, либо пишем в журнал вместе с трейсом.
