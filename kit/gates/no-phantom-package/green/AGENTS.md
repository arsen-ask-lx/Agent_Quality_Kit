# Правила проекта

## Как чинить импорты

Перед коммитом прогони кодмод:

```bash
npx jscodeshift --fix src/
```

## Форматирование

```bash
npm install prettier
```

Заполнитель, а не имя пакета: когда `npm install @types/xxx` не находит пакет типов, создай свой
файл объявлений в `types/`. Найдено замером 2026-09-14 по `Menghuan1918/drawio2go` — гейт объявил
находкой многоточие, сказанное словами, и письмо по такой находке было бы неправдой.
